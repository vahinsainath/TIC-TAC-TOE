# Tic-Tac-Toe Game

## About the Project

This project is a simple and interactive Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

The game supports two players:

- Player X
- Player O

Players take turns placing their symbols on a 3 × 3 game board. The first player to get three symbols in a row, column, or diagonal wins the game.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Two-player gameplay
- Automatic turn switching
- Winner detection
- Draw detection
- Restart game button
- Simple and responsive user interface
